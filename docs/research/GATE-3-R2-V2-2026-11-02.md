# Gate 3, R2 v2: ordinary offense population and exclusion ledger, 2022 to 2024

Status: versioned amendment of R2 under decision D1 (2026-11-02). Historical development only. Not a final acceptance.
This document does not declare revised Gate 3 passed. No 2026 data is used.

The original R2 in `GATE-3-SHOTGUN-RECONCILIATION-REVISED-2026-10-28.md` is unchanged. Its verdict (96 of 96 team-seasons
passed) stays as recorded in `data/playbooks/research-2026-10-28-gate3-shotgun-reconciliation/gate3_summary.json`.

## Why an amendment

The original R2 checks that the recomputed hierarchy value matches the builder's value for each team-season. It did not
state which plays the check covers, and it did not require an explicit ledger of the plays left out. D1 accepts the
narrower ordinary offense population as the R2 population. It requires exact agreement on that population and a complete
ledger of every play that is in one set and not the other.

## Populations

- **Gate 3 eligible.** Regular-season offense scrimmage plays (run and pass, including sacks), as in the revised gate.
- **Ordinary population.** Plays whose builder class is `scrimmage` (`snap_kind == "scrimmage"`). Ordinary play
  frequencies use only this set.
- **rev3 profile plays.** Plays in the committed rev3 profiles, which are the source of the original R2 check.
- **Audit populations.** Two-point conversions, fumbled snaps, special-teams run and pass, and aborted or unknown handling
  are not in the ordinary population. Each is reported as its own class in the ledger and never in ordinary frequencies.

## R2 v2 rule

A season passes R2 v2 when all four hold on the ordinary population.

- **(a) Exact per-play agreement.** For every ordinary play, the hierarchy value recomputed from the pinned PBP,
  participation and FTN inputs equals the value in `shotgun-provenance-<season>.jsonl`, and equals the rev3 value. Source
  labels must also agree, except for the named corrections below.
- **(b) No unexplained additions.** Every ordinary play is present in the rev3 profiles.
- **(c) Complete ledger, both directions.** Every Gate 3 eligible play outside the ordinary population is listed with its
  builder class. Every rev3 play outside the ordinary population is listed with its builder class. Unexplained = 0.
- **(d) Populations kept apart.** The classes in (c) are reported in audit populations, not in ordinary frequencies.

**Named corrections.** A source-label change may pass (a) only if it is named and approved. There is one:

| Season | Game | Play | Change | Approval |
|---|---|---|---|---|
| 2022 | `2022_15_DAL_JAX` | 4021 | source `participation` to `ftn` | D2(a): FTN token `" S"` (leading space) now reads as shotgun |

The correction changes the source label only. The value (shotgun) is the same in both builds.
