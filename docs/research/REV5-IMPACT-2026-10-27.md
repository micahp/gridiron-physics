Status: rev5 is built. rev4 is unchanged. Output: `/root/lp-snapshots/nfl-team-season-playbooks-2026-10-27-rev5` (outside git). Its BUILD-REPORT and manifest are committed under `data/playbooks/research-2026-10-27-rev5/`.

## 1. Definitions changed (names only; counts unchanged)

| rev4 class | rev5 class | Count, 2022 to 2026 | Basis |
|---|---|---:|---|
| `aborted_snap` | `fumbled_snap` | 368 run or pass | Text "FUMBLES (Aborted)" |
| `aborted_play` | `aborted_unknown_handling` | 53 run | Text "X Aborted." followed by a fumble by another player. No source states a handoff or backward pass, so the handling is unknown. |
| `broken_kick` (execution) | `dropped_kicking_operation` | 10 (9 punt, 1 field goal) | Kicking formation with the aborted flag |

The rev4 description "the player called the play off" is withdrawn. The source flag `aborted_play` only means the description contains "Aborted."

Ordinary sample: 146,252, unchanged. Formation observed 133,014, missing 13,238, unchanged. Run and pass total 147,317, unchanged. Attribution (rush and pass attempts, yards, fumbles, touchdowns) is unchanged because no source field was altered.

## 2. Speed-up, output unchanged

The builder now scans each season once, indexes each team once, hashes each source file once, builds each play record once, and validates the profiles without the per-play records.

| Build | Time | Output |
|---|---:|---|
| Before the change | about 10 to 12 minutes | rev5 |
| After the change | 260 seconds | byte-identical to rev5 for all 160 profiles, the BUILD-REPORT and the manifest |
